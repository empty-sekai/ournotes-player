# ournotes-player

[简体中文](README.md) | [English](README.en.md)

Play BanG Dream! Our Notes live charts, story episodes and Live2D models in a browser. The player renders the
data's game shaders with WebGL2 and plays sound with WebAudio. Embed a custom element, use the JavaScript API,
or host a player page in an iframe.

Version **0.2.0** reads shared object products generated by **nnnotes 0.3.x**. It also supports format 2 chart and
Live2D model sites. Game data is supplied by each user; [nnnotes](https://github.com/MetaSekaiLab/nnnotes) generates
products and static sites from that user's game files.

## Install and embed

```sh
npm install ournotes-player@0.2.0
```

With a bundler, import `ournotes-player/element`. For a plain HTML page:

```html
<script type="module" src="https://cdn.jsdelivr.net/npm/ournotes-player@0.2.0/dist/ournotes-player.element.min.js"></script>
<ournotes-player src="https://example.org/site/charts/100001_expert.json" controls></ournotes-player>
```

Start with [installation and your first site](docs/getting-started.md), then read [embedding and hosting](docs/embedding.md).
Audio begins from a user gesture. Serve game data over HTTP(S).

## Components

| Content | Custom element | JavaScript module | API |
|---|---|---|---|
| Live charts | `<ournotes-player>` | `ournotes-player` | [ChartPlayer](docs/api.md) |
| Stories | `<ournotes-story>` | `ournotes-player/story` | [StoryPlayer](docs/story.md) |
| Live2D models | `<ournotes-live2d>` | `ournotes-player/live2d` | [ModelPlayer](docs/live2d.md) |
| Experimental UI preview | `<ournotes-ui>` | `ournotes-player/ui` | [UIPlayer](docs/ui-preview.md) |

Each module has an `/element` entry that registers its custom element. Browser bundles in `dist/` provide ESM,
element-registering ESM and classic scripts, with minified files and source maps. The classic script globals are
`OurnotesPlayer`, `OurnotesStory`, `OurnotesLive2D` and `OurnotesUI`.

Live2D requires Cubism Core. Story lip sync can require MotionSync Core; home conversations require the Spine
runtime. The embedding page loads these separately under their respective licenses before creating the player.
The [runtime setup](docs/getting-started.md#browser-runtimes) describes each dependency.

## Playback

- **Live charts:** auto-perfect playback, stage and note rendering, effects, judgment UI, audio, seek, speed and
  supported Live settings. Simulation uses a fixed 60 Hz clock and float32 arithmetic.
- **Stories:** ADV commands, scene and camera effects, Live2D, localized text, video and audio. Home and afterlive
  conversations use their host products. The language selector offers languages supplied by the product.
- **Live2D:** idle animation, expressions, blinking, breathing and physics using the model's shader data.
- **UI preview:** Canvas 2D layout and a subset of UI animation from `nnnotes export ui` products.

See [fidelity](docs/fidelity.md), [story features](docs/story-features.md) and [simple stories](docs/story-simple.md)
for supported behavior. [Story authoring](docs/story-author.md) provides experimental tools for custom dialogue.

## Generate and validate data

With nnnotes configured for your inputs and the required fonts/audio tools installed:

```sh
nnnotes site build --name example -o out/site --pair 100001:expert --fonts game --player node_modules/ournotes-player
node node_modules/ournotes-player/scripts/validate-data.mjs out/site
```

A site contains chart/model/story listings, public entry manifests, immutable product manifests and shared assets.
Standalone product layouts are supported too. [Data formats](docs/data-format.md) and
[story formats](docs/story-data-format.md) describe the contracts. The validator checks their schemas and references;
browser playback checks rendering and the chosen hosting setup.

## Development

Node.js 22+:

```sh
npm ci
npm test
npm run typecheck
npm run lint
npm run contract:check
npm run build
```

Unit tests use synthetic inputs. To check a supplied data directory, run
`npm run validate-data -- path/to/site`; optional data tests use `OURNOTES_DATA` and `npm run test:data`.
See [CONTRIBUTING.md](CONTRIBUTING.md) and [CHANGELOG.md](CHANGELOG.md).

## Browser support and license

WebGL2, WebAudio, ES2022 modules, Custom Elements and ResizeObserver are required. The browser must decode the
audio/video formats present in the data. Chromium browsers are the primary playback target; brotli hosting needs
the headers described in [embedding](docs/embedding.md#hosting-the-data).
